# Identifying Education Deserts in the United States
## Cameron Diwa and Yvaine Jiang

This repository contains all the code, datasets, and visualizations produced for this project. Please refer to the writeup folder to learn more about our project.

While most datasets are included in the data folder, a few datasets were too large to upload. We have included such datasets in a google drive folder, which can be accessed [here](https://drive.google.com/drive/folders/1jI6KGnajx0vjHMQyceLYdojhpiBwlz7I?usp=drive_link). Data were collected from three main sources: the College Scorecard, the American Community Survey, and the U.S. Census Bureau. The process of cleaning and linking the data served our overarching goal of using spatial analysis techniques to locate education deserts. As such, we processed our datasets in order to be able to characterize counties by the extent to which they would be considered education deserts, via an Opportunity Score (refer to the writeup for the specific definition and how we calculated the score). It was also imperative for us to be able to link our education data with geographic data in order to map postsecondary institutions in relation to county boundaries. Once we established our map, we used selected granular data points (e.g. admit rate, completion rate, earnings, Pell Grant rate, racial composition, etc.) to assess each county's educational opportunity landscape for its students. 

This repo features a [streamlit app](https://dataviz-final-project-cameron-and-yvaine-swimwf9ee2hefy7qcjbza.streamlit.app/) built to be a diagnostic tool for education policymakers. Feel free to play around with it; perhaps it can be of use to you and your work. Please note: streamlit apps need to be woken up if they have not been run in the last 24 hours. Refer to the writeup folder to learn more about how the app works.
